# Sigma Rules

Detection rules written in Sigma format.

## Purpose

This repository contains Sigma detection rules for common attacker behaviors across Windows and Linux environments.

## Coverage Areas

- PowerShell abuse
- LOLBins execution
- Credential access
- Persistence
- Discovery
- Suspicious process execution

## Rule Structure

Each rule includes:

- Title
- Description
- Log source
- Detection logic
- False positives
- MITRE ATT&CK mapping
- Severity level

## Technologies

- Sigma
- Windows Event Logs
- Sysmon
- Microsoft Sentinel
- Splunk
- Elastic Stack

## Disclaimer

These rules are created for detection engineering practice, research and portfolio purposes.
